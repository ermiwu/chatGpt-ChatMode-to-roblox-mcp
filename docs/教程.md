# 网页直连 Roblox MCP 完整教程

这套方案让 ChatGPT 网页版通过公网 HTTPS 调用 Roblox Studio 官方 MCP。网页端无法直接访问你电脑上的 stdio 进程，因此本项目只做三件事：OAuth 授权、Streamable HTTP 与 stdio 协议桥接、Cloudflare HTTPS 隧道。

## 1. 启用 Studio 作为 MCP 服务器

1. 更新并打开 Roblox Studio，登录后载入目标 Place。
2. 打开 Assistant 的 MCP 管理界面。
3. 找到“Enable Studio as an MCP server”或对应中文选项并启用。
4. 保持该 Studio 窗口和项目打开。

界面版本可能变化。你应看到的关键状态是：Studio 允许官方 MCP 访问，且本机存在 `%LOCALAPPDATA%\Roblox\mcp.bat`。本项目不会连接 Studio 的插件端口。

## 2. 下载项目并安装依赖

```powershell
git clone <你的私有仓库地址>
Set-Location '网页直连roblox mcp'
npm install
```

只想验证 Studio 时可先执行：

```powershell
npm run build
npm run doctor
```

四项检查分别对应：官方批处理文件、MCP 握手、工具目录、Studio 会话。最后一项失败通常表示 Studio 没开、项目还没载入，或 Studio 内的 MCP 开关未启用。

## 3. 一键启动公网网关

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\start.ps1
```

脚本会完成：

1. 检查 Node.js 与 Roblox 官方 `mcp.bat`。
2. 将 Cloudflare 官方二进制下载到 `.tools/`。
3. 构建项目并创建 Quick Tunnel。
4. 生成随机 OAuth 批准密码和令牌签名密钥。
5. 只把配置写到 Git 忽略的 `.env.local`。
6. 执行诊断并启动本地网关。

不要关闭此 PowerShell 窗口。复制终端显示的 MCP URL 和 OAuth approval password；不要复制 `.env.local` 中的签名密钥。

## 4. 在 ChatGPT 创建自定义 App

1. 在 ChatGPT 设置中进入“安全与登录”，打开开发者模式。
2. 打开 `chatgpt.com/plugins`，创建新的自定义 App。
3. 名称填写“网页直连 Roblox MCP”。
4. MCP Server URL 填写终端显示的完整 `/mcp` 地址。
5. 认证选择 OAuth，然后保存并连接。

本教程把这组网页功能统称为 ChatGPT Developer Mode。若页面字段名称略有变化，以“MCP URL”和“OAuth”为关键字选择即可。

## 5. 完成 OAuth 授权

连接时会跳转到网关的授权页。页面会显示请求方、回调地址和权限范围：

1. 核对地址来自你刚启动的 `trycloudflare.com` 域名。
2. 输入终端中的 OAuth approval password。
3. 只点击一次“批准”，等待页面自动返回 ChatGPT。

授权请求是短期、一次性的。重复点击、返回旧页面或等待太久都会得到 `authorization request is invalid or expired`；此时回到 ChatGPT 重新发起连接即可。

## 6. 验证读取操作

先让 ChatGPT 执行：

> 调用 `list_roblox_studios`，只列出当前 Studio，不做修改。

若只开一个项目，通常会返回一个条目。若返回多个条目，复制正确的 `studio_id`，并在后续提示中明确写“所有调用使用这个 studio_id”。然后尝试 `get_studio_state` 或 `search_game_tree`。

## 7. 安全验证写操作

官方 MCP 可能公开 `execute_luau`、`multi_edit` 等写操作。建议按以下顺序测试：

1. 保存 Studio 项目或创建版本。
2. 要求 ChatGPT 先说明将调用的工具、目标实例和参数。
3. 从容易撤销的小改动开始，例如创建一个临时 Folder。
4. 在 Studio 中确认结果，再决定是否继续。
5. 测试后撤销或删除临时对象。

工具目录来自 Roblox 官方 MCP，Studio 更新后名称可能变化。本项目对未知工具采取保守的“可能写入”标记。

## 8. 使用固定域名的长期隧道

Quick Tunnel 适合试用，但 URL 会变化。长期使用可在 Cloudflare Zero Trust 创建 Named Tunnel，将一个 HTTPS 主机名指向 `http://127.0.0.1:58742`，然后自行创建 `.env.local`：

```dotenv
PUBLIC_BASE_URL=https://你的固定域名
REMOTE_HOST=127.0.0.1
REMOTE_PORT=58742
MCP_AUTH_PASSWORD=一个随机长密码
MCP_TOKEN_SECRET=至少32字符的随机密钥
ALLOWED_ORIGINS=https://你的固定域名
```

执行 `npm run build`、`npm run doctor`、`npm start`，并将固定的 `/mcp` 地址填入 ChatGPT。Cloudflare Tunnel 的凭据同样不得提交 Git。

## 9. 停止服务与清理

正常停止服务：回到启动脚本窗口按 `Ctrl+C`。`.env.local`、`.tools/` 和 `logs/` 都已被 Git 忽略；如不再使用，可单独移到回收站。无需修改 Roblox 项目，也没有 Studio 扩展需要卸载。

## 10. 故障排查

### `找不到 Roblox 内置 MCP`

更新 Roblox Studio，至少启动一次，再检查 `%LOCALAPPDATA%\Roblox\mcp.bat`。企业策略或非标准安装可能需要在 `.env.local` 设置 `ROBLOX_MCP_COMMAND`。

### `未发现 Roblox Studio`

确认 Studio 已打开具体项目，并在 Assistant 的 MCP 管理界面启用官方服务。然后重新运行 `npm run doctor`。这与网页隧道无关。

### ChatGPT 能看到 App，但工具调用超时

查看终端是否仍在运行；打开公网地址的 `/health` 检查 `connected`、`studioConnected` 和 `toolCount`。再看 `logs/cloudflared.log`。不要把日志中的临时 URL 当作永久地址。

### OAuth 第一次点批准没反应，第二次显示已过期

旧审批已经被消费或超时。回到 ChatGPT 删除失败连接并重新连接；只在新授权页点击一次。浏览器必须允许跳转回 ChatGPT 的回调地址。

### `401 unauthorized`

令牌可能随网关重启而失效。重新连接 App 并完成一次 OAuth。不要复用另一条隧道签发的令牌。

### `403 Host/Origin is not allowed`

`PUBLIC_BASE_URL`、隧道域名和 `ALLOWED_ORIGINS` 不一致。Quick Tunnel 请重新运行脚本并把新 MCP URL 更新到 App；固定域名请同步修改 `.env.local`。

### 查看本地日志

- 网关日志：启动 PowerShell 窗口。
- 隧道日志：`logs/cloudflared.log`。
- Studio 输出：Roblox Studio 的 Output / MCP 管理界面。

报告问题时请隐藏 OAuth 密码、访问令牌、签名密钥和 Cloudflare 凭据。
